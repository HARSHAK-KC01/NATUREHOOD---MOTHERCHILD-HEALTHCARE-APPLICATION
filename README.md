# Nurturehood - Maternal & Child Health Platform 🌿👶

> **Every Mother. Every Child. Every Care.**  
> A high-performance, offline-first digital healthcare platform engineered for field healthcare workers (ANMs, ASHA workers), clinical supervisors, district administrators, and parents.

---

## 🌟 Overview

Nurturehood empowers grassroots healthcare delivery with modern web technologies, offline synchronization, ABDM/RCH compliance, and localized multilingual support across India's regional languages.

### Core Modules & Capabilities:
- **📊 Real-time Clinical Dashboard**: High-risk pregnancy detection, immunization trends, coverage rates, and priority task alerts.
- **💉 Immunization Tracker & Mission Indradhanush**: Age-specific dose schedules (BCG, OPV, Pentavalent, Rotavirus, MR, DPT Booster) with automated SMS reminders.
- **🤰 Antenatal Care (ANC)**: Trimester-by-trimester tracking, vitals monitoring (BP, Hemoglobin, weight gain), and high-risk flags.
- **👶 Unified Mother-Child Health Record**: One-stop longitudinal family health record linking siblings, birth history, and growth percentiles.
- **🏥 Hospital Network Connectivity**: Live bed capacity, ICU availability, blood bank units, and referral routing between Sub-Centers, PHCs, CHCs, and District Hospitals.
- **📱 ABDM QR / ABHA Scanner**: Instant patient profile retrieval via camera scanning or manual RCH ID search.
- **🗺️ GIS Health Vulnerability Mapping**: Coverage maps highlighting under-served pockets and campaign reach.
- **💬 Community Health Wall**: Field alerts, announcements, and peer-to-peer clinical guidance.
- **🌐 Multilingual Support (i18n)**: Instant dynamic switching between English, Hindi (हिन्दी), Kannada (ಕನ್ನಡ), Tamil (தமிழ்), Telugu (తెలుగు), Bengali (বাংলা), Marathi (मराठी), and Spanish (Español).
- **✨ Optimized GPU Animations**: Fluid 60 FPS transitions powered by Framer Motion.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/HARSHAK-KC01/NAUTUREHOOD.git
cd NATUREHOOD

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Production Build
```bash
npm run build
```

- **Styling**: Tailwind CSS + Radix UI Primitives
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Notifications**: Sonner
- **Mapping**: Leaflet
